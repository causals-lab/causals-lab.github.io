Use a fixed snapshot of the news-derived Causals Graph for research and tools. We publish the data structure and its limits together. A recorded relationship is not, by itself, a verified causal effect.

Current snapshot

v0.1.0 2026-10-09

View version on GitHub ↗

369,184 nodes · 1,272,418 directed edges · 41 observed relation codes. This is a filtered historical snapshot, not the live graph shown in Explore. Person nodes, news headlines, article text, URLs, and private inference rules are not in this download. The same version is also available as a Hugging Face dataset ↗, with separate nodes and edges configurations.

Start with a small sample. The 10-minute notebook ↗ uses 62 real nodes and 9 edges to show how to join records and inspect source IDs. Run it in Colab ↗ or download the sample ↗; no private software, database, or API key is needed. The selected sample is not representative or independently validated as causal fact.

01 / USE

Join by ID.

Each file has one JSON object per line. Edge source_id and target_id join to node id. A source-news ID joins to a news node, but the article URL is not released.

02 / VERIFY

Check the files.

The manifest contains SHA-256 hashes for both compressed files. Verify them after download. IDs are referenceable within this version; cross-version stability has not been established.

03 / INTERPRET

Read the caveats.

SHIFTED is an observation. TRIGGERED and STATED_CAUSE are extracted or attributed claims, not independently verified causal effects. Some records lack a released source-news link.
