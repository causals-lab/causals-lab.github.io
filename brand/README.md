# Causals Lab visual identity

The mark is a small causal graph: a source, a reviewed junction, one visible path, and one unresolved branch. The open amber node is deliberately **not** a second proven outcome. It represents a claim that can be questioned. The symbol should not be interpreted as a scientific certification of any specific causal relationship.

## Assets

| File | Use |
| --- | --- |
| `mark.svg` | Transparent symbol on dark backgrounds |
| `avatar.svg` | Master artwork for square social and GitHub avatars |
| `avatar-512.png` | GitHub organization avatar, 512 × 512 px |
| `lockup.svg` | Horizontal wordmark on dark backgrounds |
| `../favicon.svg` | Simplified small browser icon |

## Core palette

| Token | Color | Role |
| --- | --- | --- |
| Deep navy | `#0c1820` | Primary background |
| Signal mint | `#7ee0ca` | Structural path and primary action |
| Evidence amber | `#e2b472` | Reviewed junction, alternate claim |
| Soft ivory | `#e9f1ec` | Primary text |
| Muted sage | `#abc4bf` | Secondary text |

The mint path is solid; the amber alternative is dotted and ends open. Do not turn the open node into a filled node, remove the alternate branch, or recolor the mark with a spectrum that implies a confidence scale. Do not stretch, rotate, add drop shadows, or place it on a similar-toned background. Leave at least one node diameter of clear space around the symbol.

## Typography and placement

Use a clean system sans-serif for navigation and wordmarks; editorial serif headings can use Georgia. In GitHub's circular avatar crop, use the square `avatar-512.png`; all four nodes fit inside the safe central circle. Use the simplified `favicon.svg` at browser-tab sizes. For print or high-resolution work, use the SVG masters rather than enlarging a PNG.

## Relationship to the app

Causals Lab's visual identity identifies the open research initiative. Moirai is a separate application and should not adopt the Lab mark as a product badge without a distinct product-brand decision.
